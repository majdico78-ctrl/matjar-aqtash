# محمد الأقطش للمجمدات — متجر إلكتروني

متجر أردني كامل (واجهة عربية + خادم Node.js) يضم:

- **واجهة الزبون**: عرض المنتجات بالتصنيفات، شريط العروض، سلة، طلبية توصيل أو استلام
- **تحديد موقع الزبون**: خارطة جوجل (قمر صناعي/شوارع) + الموقع المحفوظ على الجهاز
- **لوحة المتجر**: المنتجات والأسعار والصور، الطلبيات الواردة (عرض الطلب ← تجهيز ← تسليم)، خدمة التوصيل، أرصدة الزبائن
- **صفحة الموظف**: الطلبيات الحية تتحدث تلقائياً + زر اتصال + التوجه إلى الموقع

## التشغيل

```
npm install
npm start
```

يعمل على المنفذ 3000 (أو أي منفذ بمتغير `PORT`).

## البنية

- `server.js` — الخادم كاملاً بواحد: واجهة ثابتة + مسارات البيانات + بلاطات الخارطة
- `public/` — واجهة المتجر (النسخة المبنية)
- `data/` — ملفات JSON (تُنشأ تلقائياً، غير مرفوعة لجيت هب)

## النشر على Render

1. New Web Service → اختر هذا المستودع
2. Build Command: `npm install` · Start Command: `npm start`
3. الرابط العام يصدر فوراً بعد أول نشر
